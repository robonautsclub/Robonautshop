# Task 06 — Footer

## Goal

Add a simple footer that matches the navbar.

## In scope

- `components/layout/footer.tsx`
- Mount it in `app/(store)/layout.tsx`
- Brand: Robonautshop
- Same nav links as the navbar
- One short line that the store serves robotics builders in Bangladesh and can expand later
- Copyright year from the current date

## Out of scope

- Newsletter forms, social links that go nowhere, contact forms, or payment logos
- New pages

## Steps

1. Inspect the navbar and store layout. Reuse the same link list if one already exists.
2. Run `pnpm lint` and `pnpm typecheck`.
3. Stop. Do not start task 07.

## Done when

- Footer renders under page content
- Links match the navbar
- Lint and typecheck pass
